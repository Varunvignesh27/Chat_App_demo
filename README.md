⚡ Zero Polling, Zero Latency: Powered by pure, bidirectional WebSockets for instant message delivery.

🔌 Fail-Safe Connection: Uses SockJS to guarantee connectivity, falling back to HTTP streaming when WebSockets are blocked.

🧠 Smart Activity Tracking: Spring Event Listeners capture connection lifecycles to announce active users instantly.

🎨 Dynamic Identity Generation: Color-coded user avatars generated dynamically on the fly based on username hashing.

🚀 Zero Setup Overhead: Minimalist frontend served directly by the backend container—no heavy NPM builds needed.
